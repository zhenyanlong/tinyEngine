# 待办功能清单维护

本 skill 用于维护项目根目录下的 `todolist.md` 文件——一个记录"今天想做但暂时搁置，留待以后实现"的功能点清单。

## 文件位置

`e:/Projects/tinyEngine/todolist.md`

## 文件结构

```
# 待办功能清单
---
## 记录格式
...（说明）...
## 待办
- [ ] 【描述】
  - 上下文 / 阻塞原因
  - 日期
## 已完成
- [x] 【描述】
  - 日期
```

## 操作指令

### 查询待办

- 用户说「看下 todolist」「还有什么没做」→ 读取文件，列出「待办」区的条目

### 添加待办

- 用户说「记个 todo」「这个先记下来」「搁置这个功能」→ **先确认**用户要记录的功能点描述和阻塞原因，然后在「待办」区添加条目：

  ```markdown
  - [ ] 【{一句话描述}】
    - 上下文：{为什么想做 / 阻塞原因 / 依赖}
    - 日期：{当前日期 YYYY-MM-DD}
  ```

- **禁止代用户推测描述或原因**，必须从对话中提取或向用户确认

### 完成待办

- 用户说「这个 todo 做完了」「可以划掉了」→ 将对应条目从「待办」移到「已完成」，`[ ]` 改为 `[x]`

### 删除待办

- 用户说「删掉这个 todo」→ 移除对应条目

### 整理

- 用户说「整理下 todolist」→ 按日期倒序重新排列条目
